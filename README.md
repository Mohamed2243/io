# Mohamed Abdelhamed — Portfolio

My personal portfolio site. It highlights the business and healthcare applications I've worked on — radiology management, coaching CRM, medical marketplace platforms, and client-facing websites.

**Live site:** [mohamed2243.github.io/io](https://mohamed2243.github.io/io/)

## Tech

Vite, TypeScript, and vanilla CSS. No React on the site itself — just a fast static build deployed through GitHub Pages.

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

Output goes to `dist/`, which is what GitHub Pages serves.
